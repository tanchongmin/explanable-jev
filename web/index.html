Jev-style typed evaluator

Constrain model judgments to Choice, Score, and True/False outputs.

State

? State is the shared context every question sees. Add key-value fields like ticket_message, policy, or account_tier.

Questions

? Questions are independent typed judgments run against the same state. Add one or more, then evaluate them together.
? Choice returns exactly one option key from the options you provide. ? Score returns a number on your ordered rubric, starting at 0 for the first level. ? True/False returns true or false for a yes/no judgment.

Answers

? Answers show the interpreted result for each question. The raw JSON panel shows only question-to-answer output.
